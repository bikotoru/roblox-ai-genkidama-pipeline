# Prompts listos para usar

## Genkidama R6 completa

```
Usa RBSmithy + animate-roblox-characters + blender-skills.

Crea una secuencia completa de Genkidama estilo Goku para personaje R6:

1. Animación R6 (5-7s):
   - Levanta ambos brazos al cielo como Goku cargando Genkidama.
   - Pose de concentración, cuerpo ligeramente inclinado hacia atrás.
   - Keyframes limpios, foot-lock, export .rbxanim o FBX.

2. VFX:
   - Orbes de energía que llegan desde el entorno hacia las manos.
   - Bola Genkidama que crece encima de las manos (mesh + glow + swirls).
   - Flipbooks / texturas animadas si es necesario.

3. Integración en Studio (MCP):
   - Importa animación y assets.
   - ParticleEmitters para energías entrantes.
   - MeshPart de la bola + emitters internos.
   - Animation Events en los frames correctos.
   - Scripts (Local + Server) seguros con validación.

Itera y corrige hasta que se vea bien.
```
